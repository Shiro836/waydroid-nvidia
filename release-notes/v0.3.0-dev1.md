Development build from the `rust-rewrite` branch. Not a release: it exists to test the new driver source before it
reaches `main`.

## What's different from v0.2.0

- **The driver is built from [Shiro836/nvidia-prolapse](https://github.com/Shiro836/nvidia-prolapse)** instead of a
  copy inside this repository. The build pins one commit of it and records which one in the bundle.
- **Vulkan error codes follow the specification.** Out-of-memory, an invalid external handle, a failed export and
  similar failures now return their own error instead of reporting the device as lost.
- **A lost GPU device is torn down more cleanly.** Its channels are freed without signalling work that never ran,
  and creating, signalling or resetting a semaphore still works after the loss, as in NVIDIA's own driver.
- The opt-in native GL driver reports itself as `nvidia-prolapse (nvrm)`.
