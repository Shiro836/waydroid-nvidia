Test version of the new `nvidia-prolapse` mode: an open-source NVIDIA driver running right inside Android.

## What's new

- **Fedora works.** Fedora's LXC has no AppArmor support, so the container config we generated could not be loaded
  (#27, #17). The AppArmor line is now only written when your LXC accepts it. The installer also loads the SELinux
  policy that Fedora's own waydroid package carried, so Android boots with SELinux enforcing, and it puts Waydroid's
  network interface into firewalld's trusted zone so Android gets network. No manual config edits needed.
- **Setup works on non-English systems.** Setup read the text output of tools like `readelf`, which is translated on
  e.g. a Spanish system, and then failed with `library "libdl.so" not found` (#28). It now reads what it needs
  directly and runs its tools in the C locale.
- **GTX 10xx and other pre-Turing GPUs install.** Our hardware video decoder supports Turing (GTX 16xx, RTX 20xx) and
  newer for now. On older GPUs setup used to stop at the media check; it now installs and tells you that hardware
  video decode isn't available on your GPU, and Android uses its software decoders instead.
- **Fresh Ubuntu 24.04 installs.** Setup no longer refuses the GPU because of the render node's default permissions
  after a reboot. On systems with Python older than 3.11 (Ubuntu 22.04), the installer now stops right away and says
  why, instead of failing halfway.

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/Shiro836/waydroid-nvidia/public-test/packaging/install.sh | sudo bash
sudo waydroid-nvidia-setup
waydroid session start
```

For Google apps on a new install, use `sudo waydroid-nvidia-setup -s GAPPS`. Updating from an earlier rc is the same
commands. On Fedora, remove Fedora's own waydroid first (`sudo dnf remove waydroid`); the installer tells you if it
is still there. Supported GPUs, drivers and known issues are in the
[README](https://github.com/Shiro836/waydroid-nvidia/tree/public-test#readme).
